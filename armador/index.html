Conectar con GitHub

Con esto el armador publica las rutinas y sube los GIF solo, sin que entres a github.com.

  1. Abre esta página de GitHub (token de acceso personal, tipo fine-grained).
  2. En Repository access elige Only select repositories y marca CreadorDeRutinas.
  3. En Permissions → Repository permissions, pon Contents en Read and write. No hace falta nada más.
  4. En Expiration elige el plazo que quieras; cuando caduque, repites esto.
  5. Pulsa Generate token, cópialo y pégalo aquí abajo.

El token se guarda solo en este navegador, nunca en el repositorio. Dale permiso únicamente a este repositorio: así, lo máximo que alguien con acceso a tu computadora podría tocar son tus rutinas.

Guardar tus ejercicios

Descarga el archivo y reemplaza ejercicios.js en tu repositorio.

  1. Abre ejercicios.js en github.com y pulsa el lápiz.
  2. Selecciona todo, borra y pega el contenido del archivo descargado.
  3. Commit changes.

Archivos de la rutina

  1. Crea en tu computadora una carpeta llamada y mete dentro el index.html.
  2. En github.com, Add file → Upload files y arrastra la carpeta completa.
  3. Commit changes.
El respaldo NO se sube a GitHub.

Lleva la clave sin cifrar. Guárdalo en tu computadora: es lo que te deja volver a editar la rutina.
